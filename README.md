# Тайм-трекер
#Автор Лыкин Владислав Дэ21-25
Кросс-платформенный недельный тайм-трекер: Electron + Vite + React + TypeScript (strict).
Блоки недели по проектам, планирование на будущее, таймер, напоминания, отчёты и CSV.
Полное ТЗ: `tz-tracker-crossplatform.md`. Решения: `DECISIONS.md`. Известные проблемы: `KNOWN_ISSUES.md`.

## Возможности

- Недельный/дневной/списочный календарь (FullCalendar), выделение мышью → блок.
- Проекты с цветами и архивом; суммы потраченного по проектам (сайдбар).
- Планирование: плановые блоки (пунктир), «план недели» в шапке; прошлое плана считается фактом.
- Таймер: старт/стоп (панель, Space, меню трея); активный блок растёт в календаре.
- Напоминания: за N минут до старта, системное уведомление; просроченные дальше часа — тихо.
- Отчёт за период + экспорт CSV (BOM + `;` — открывается в Excel/Pages без настройки кодировки).
- Трей (крестик прячет в трей, таймер идёт), закрытие/восстановление повреждённого файла.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `Cmd/Ctrl + N` | новый блок на текущий час |
| `Space` (вне полей ввода) | старт/стоп таймера |
| `Cmd/Ctrl + E` | открыть отчёт (экспорт — кнопкой) |
| `Esc` | закрыть диалог |

На macOS трей доступен всегда; на Windows/Linux иконки трея и хоткеи зависят от окружения
(интерфейс платформы сообщает о доступности, приложение работает и без них).

## Запуск из исходников

Требуется Node.js >= 22 (локально проверялось на 26).

```bash
npm ci
npm run dev          # Electron-приложение
npm run dev:browser  # тот же UI в браузере: http://localhost:5173 (localStorage, без трея/уведомлений)
npm test             # unit-тесты shared-слоя (Vitest)
npm run typecheck    # строгие типы (node + web)
npm run build        # out/main, out/preload, out/renderer
npm run preview      # собранный билд в Electron; TZ_SMOKE_SHOT=1 — автоматический smoke
```

## Сборка установщиков

```bash
npm run build && npm run dist
# macOS: dist/*.dmg (arm64, без подписи — первое открытие правым кликом, см. приёмку)
# Linux: dist/*.AppImage; Windows: dist/*-setup.exe (NSIS)
```

CI (`.github/workflows/build.yml`) собирает три ОС на tag `v*` или вручную (Run workflow):
typecheck → тесты → build → electron-builder, артефакты в Workflow artifacts.

## Где лежат данные

| Режим | Путь |
|---|---|
| `npm run dev` / `preview` | каталог проекта `.data/db.json` |
| собранное приложение, macOS | `~/Library/Application Support/tz-tracker/db.json` |
| собранное приложение, Windows | `%APPDATA%\tz-tracker\db.json` |
| собранное приложение, Linux | `~/.config/tz-tracker/db.json` |
| браузерный режим | localStorage, ключ `tz-tracker.db.json` |

Перед каждой записью файл копируется в `db.backup.json`; битый файл сохраняется в
`db.corrupt.json` и восстанавливается из бэкапа (или стартует с чистой БД, если бэкап тоже битый).

## Ручная приёмка (после сборки)

- [ ] CSV: создал блок → «Отчёт» → «Экспорт CSV» → файл открывается в Excel/Pages/Sheets,
      русские без кракозябр, колонки разошлись, сумма = сайдбару.
- [ ] Крестик → трей, таймер продолжает идти, из меню трея стоп → блок в календаре.
- [ ] Напоминание: блок на +2 минуты с напоминанием «в момент старта» → уведомление один раз,
      повторного нет после перезапуска.
- [ ] План: блок на завтра → пунктир и «план недели»; после наступления — обычный блок.
- [ ] macOS unsigned: первое открытие через правый клик → «Открыть»
      (или `xattr -dr com.apple.quarantine /Applications/TZ\ Tracker.app`).
