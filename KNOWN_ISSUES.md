# KNOWN_ISSUES.md

- **Одна копия повреждённого файла.** Битый файл сохраняется в `db.corrupt.json` поверх
  предыдущей такой копии: при повторном повреждении старое доказательство теряется.
  Влияние: сложность диагностики редкого сбоя. Не планируется усложнять (нумерованные копии).
- **Browser-режим без бэкапа.** В localStorage одна запись, поэтому повреждение =
  чистый старт с сообщением (восстанавливать не из чего). Влияние: только dev-режим.
- **Блокировка too-new — на процесс.** Если внешняя программа заменит файл на совместимый,
  запись останется отключённой до перезапуска. Влияние минимально (сценария в ТЗ нет).
