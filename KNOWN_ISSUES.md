# KNOWN_ISSUES.md

- **Одна копия повреждённого файла.** Битый файл сохраняется в `db.corrupt.json` поверх
  предыдущей такой копии: при повторном повреждении старое доказательство теряется.
  Влияние: сложность диагностики редкого сбоя. Не планируется усложнять (нумерованные копии).
- **Browser-режим без бэкапа.** В localStorage одна запись, поэтому повреждение =
  чистый старт с сообщением (восстанавливать не из чего). Влияние: только dev-режим.
- **Блокировка too-new — на процесс.** Если внешняя программа заменит файл на совместимый,
  запись останется отключённой до перезапуска. Влияние минимально (сценария в ТЗ нет).
- **Напоминания живут только с процессом** (ТЗ §4: фонового демона и автозапуска нет).
  Если момент напоминания прошёл при закрытом приложении — при старте оно не показывается
  (просрочка дальше 60 минут помечается прочитанной, чтобы не копить). Влияние: плановое
  мероприятие без запуска приложения остаётся без уведомления — календарь его не теряет.
- **Показ уведомления зависит от ОС**: на macOS unsigned dev-сборке система может не
  показать Notification (на собранном приложении показывается); в smoke это не проверяемо —
  проверяется сквозной сигнал и отметка reminderFiredAt. Влияние: cosmetic на dev-машине.
